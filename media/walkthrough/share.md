# Share with an agent

**Share with agent** lets agents read the logs in this window until you stop. Common credentials are redacted, and agents cannot run or stop anything.

**Set Up for My Agent** does it in one step: it turns on terminal capture, shares, and connects the agent found in your editor.

The arrow beside the button chooses what they read (everything, or specific runs) and connects Claude Code or Codex.

**Investigate**, on an error in the Logs panel or its mark in the editor, hands that one error to Copilot, Claude Code, or Codex to find the cause and fix it, and Logline then tells you whether it is fixed.
