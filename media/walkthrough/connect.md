# Add a connection

Search and tail production logs in Datadog, the log table of a Postgres or MySQL server (Aurora and RDS too) or a SQLite file, or a MongoDB collection, next to the runs you capture.

Your search becomes the store's own query, shown before it runs, and every query is read-only. Passwords and keys stay in VS Code's secret storage, and Aurora and RDS can sign in with AWS IAM instead.
