Search syntax

Press Enter to apply a term. Click a filter chip to edit it, or × to remove it.

error timeout
Free text — matches all words
"database timeout"
Exact phrase
-timeout
Exclude a word or filter
a OR b
Either side matches
level:error
Field filter (severity, msg, service, requestId, traceId, spanId, durationMs and more all work as aliases)
status:5xx
Wildcard: 2xx / 4xx / 5xx
status:>=500
Numeric comparison: > >= < <=
status:[500 TO 599]
Numeric range
message:/time.?out/i
Regex, with optional flags
exists:requestId
Field is present on the event
last:15m
Relative time: s / m / h / d
changed:true
Logged by, or failing in, code changed since the last commit
timestamp:[2026-01-01 TO 2026-01-02]
Absolute time range
